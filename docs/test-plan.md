# ERFA FARMS Test Plan

- Auth: register/login/logout/reset for customer/staff/admin
- Role checks: verify admin-only pages/APIs reject non-admin
- Catalog: list/filter/search/product-details
- Cart/wishlist: add/update/remove flows
- Checkout/payments: create order, initialize reference, verify payment
- Order management: admin status updates and customer history
- Farm modules: create/list livestock/crops/inventory/tasks, staff task status
- Finance: add/list income and expenses
- Notifications: admin create + user list/mark-read
- Reports: KPI summary endpoint and admin dashboards
